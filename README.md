# GSAP Awwwards

A polished, Awwwards-inspired landing page built with React, Vite, and GSAP. The project focuses on smooth scrolling, cinematic motion, and premium brand storytelling to create a modern product showcase experience.

## Overview

This project recreates the feel of a high-end award-winning marketing site with:

- immersive hero sections
- layered motion-based storytelling
- GSAP scroll-triggered animations
- smooth scrolling effects
- responsive layout for desktop and mobile
- elegant product and nutrition storytelling sections

## Tech Stack

- React 19
- Vite
- GSAP + ScrollTrigger
- Tailwind CSS
- @gsap/react

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal.

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Project Structure

```text
src/
  components/      Reusable UI elements such as navbar and sliders
  sections/        Page sections like hero, flavor, testimonials, footer
  constants/       Shared constants and content data
  App.jsx          Main page composition
  index.css        Global styles and visual design
public/            Static assets
```

## Scripts

- `npm run dev` — starts the Vite development server
- `npm run build` — creates a production build
- `npm run preview` — previews the production build locally
- `npm run lint` — runs ESLint checks

## Notes

This is a front-end showcase project meant to highlight animation design and layout composition rather than a full business application or backend system.
